- [Create Order Record](https://triplewhale.readme.io/reference/create-order-record.md): Ingest order data into Triple Whale for Custom Sales Platforms.   This endpoint allows users to upload  detailed order information,  including customer details, product information, transaction totals,  discounts, refunds, and shipping details.
- [Bulk Create Order Records](https://triplewhale.readme.io/reference/bulk-create-order-records.md): Ingest multiple order records into Triple Whale for Custom Sales Platforms.   This endpoint allows users to upload batches of order information, including customer details, product information, transaction totals, discounts, refunds, and shipping details.
- [Create Product Record](https://triplewhale.readme.io/reference/create-product-record.md): Ingest product data into Triple Whale. This endpoint allows users to upload detailed product information, including variants, tags, collections, and images.
- [Create Subscription Record](https://triplewhale.readme.io/reference/create-subscription-record.md): Ingest subscription data into Triple Whale. This endpoint allows users to upload detailed subscription information, including customer details, items, status, and metadata.
- [Create Customer Record](https://triplewhale.readme.io/reference/create-customer-record.md): Ingest customer data into Triple Whale. This endpoint allows users to upload detailed customer information — including contact details, address, consent status, and purchase history metadata.
- [Create Ad Record](https://triplewhale.readme.io/reference/create-ad-record.md): Ingest ad data into Triple Whale. This endpoint allows users to upload  detailed ad information, including campaign, adset, ad details, and  performance metrics.
- [Create Email/SMS Record](https://triplewhale.readme.io/reference/create-email-sms-record.md): Ingest email, SMS, and direct mail marketing data into Triple Whale. This endpoint accepts campaign, flow, and message attributes along with performance metrics.
- [Create Post-Purchase Survey (PPS) Record](https://triplewhale.readme.io/reference/create-pps-record.md): Ingest PPS data into Triple Whale. This endpoint allows users to upload  detailed post-purchase survey information, including order-related data, questions, and responses.
- [Enrich Orders Data](https://triplewhale.readme.io/reference/enrich-orders-data.md): Use this endpoint to enrich existing orders—such as adding shipping costs or custom tags.  Note: Supported for data from platforms with a native Triple Whale integration  (e.g., Shopify, BigCommerce, WooCommerce).  Not supported for Custom Sales Platforms—to update these, resend the full order via the [Orders](https://triplewhale.readme.io/reference/create-order-record) endpoint.
- [Enrich Products Data](https://triplewhale.readme.io/reference/enrich-products-data.md): Use this endpoint to enrich existing products—such as adding cost data from external systems.  Supported for data from platforms with a native Triple Whale integration  (e.g., Shopify, BigCommerce, WooCommerce).  Not supported for Custom Sales Platforms—to update these, resend the full product record via the  [Products](https://triplewhale.readme.io/reference/create-product-record) endpoint.
- [Enrich Pixel With Offline Events](https://triplewhale.readme.io/reference/enrich-pixel-with-offline-events.md): Send offline or server-side Pixel events—such as leads, MQLs, SQLs, opportunities, book-a-demo events, or fully custom events—into Triple Whale.  Rate limit is 1,000 events/min. Max payload is 3 KB. When `type = custom`, you can add additional properties of type **Number, Float, String, Boolean, or Date**.
- [Create Compliance Data Deletion Request](https://triplewhale.readme.io/reference/create-compliance-request.md): Create a compliance request to delete/mask customer PII for a shop using one or more identifiers (emails and/or phone numbers).
- [Sample Automation: Submit Deletion Requests from a CSV (Python)](https://triplewhale.readme.io/reference/sample-automation-submit-deletion-requests-from-a-csv-python.md)

- [Get Summary Page Data](https://triplewhale.readme.io/reference/get-summary-page-data.md): Retrieve data from the Summary Page for a specified time period.
- [Get Customer Journey Attribution Data](https://triplewhale.readme.io/reference/get-customer-journey-attribution-data.md): Export full customer journey data, with Triple Pixel attribution, for all customers who placed an order in the specified period.
- [Execute Natural Language Query (Moby AI)](https://triplewhale.readme.io/reference/data-out-execute-natural-language-query-moby.md): Process natural language prompts to retrieve data. This endpoint interprets user-provided questions and generates SQL queries to fetch the desired results. The response returns the query results in a JSON format, grouped based on the question.
